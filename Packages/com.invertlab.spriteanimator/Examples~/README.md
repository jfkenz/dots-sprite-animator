# DOTS Sprite Animator Examples

This package ships as a portable flipbook animation toolkit.

Typical sample content for project integration:

1. A spritesheet texture
2. A `ScriptableSpriteSheetProfile` asset
3. A scene with `SpriteAnimSetAuthoring` configured from that profile
4. A script that switches clips via `SpriteAnims.Play(...)`

Use `Documentation~/QuickStart.md` for the full setup flow.
